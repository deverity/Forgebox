# forge-tls

**O que é:** CA local, certificados folha (SAN do host e wildcard), instalação no trust store do usuário e renovação.

**O que não é:** Não usa ACME nem CA pública (previsto só no M5).

**Quem depende dele:** `forge-daemon`.

**Referência:** [docs/06-sites-vhosts-multi-php.md](../../docs/06-sites-vhosts-multi-php.md) e [docs/11-security.md](../../docs/11-security.md).
