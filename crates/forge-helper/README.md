# forge-helper

**O que é:** Binário `forgebox-helper.exe`: operações elevadas (NRPT, hosts, firewall) com allowlist estrita e log.

**O que não é:** Não é um serviço do Windows e não aceita comandos fora da allowlist.

**Quem depende dele:** ninguém diretamente; é invocado sob demanda com UAC.

**Referência:** [docs/11-security.md](../../docs/11-security.md).
