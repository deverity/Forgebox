# forge-sites

**O que é:** Modelo de site, drivers de framework (Laravel, WordPress...), parked dirs, vhosts, proxies e apps (Procfile).

**O que não é:** Não renderiza arquivos de configuração (isso é `forge-render`) e não mexe em DNS nem em certificados.

**Quem depende dele:** `forge-daemon`.

**Referência:** [docs/06-sites-vhosts-multi-php.md](../../docs/06-sites-vhosts-multi-php.md).
