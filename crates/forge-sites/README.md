# forge-sites

**O que é:** Modelo de site (validação de host/aliases, `SiteDraft`, `SiteService` com eventos `site.*`), drivers de framework (Laravel, Symfony, WordPress, CakePHP, Drupal, Magento, generic-php, static, spa), conversão `Site` → `VhostModel`, parked dirs (watcher `notify`) o loader de `forgebox.yaml` (`ProjectPlan`) e a paridade Linux dos projetos ([docs/15](../../docs/15-linux-parity-case-sensitivity.md), [ADR-0026](../../docs/adr/0026-case-conversion-tree-recreation-and-mismatch-finder.md)): Case Mismatch Finder (`lint_case`: referências com caixa diferente do disco em PHP/Blade/Twig/HTML/JS/CSS/manifestos/PSR-4, nomes duplicados por caixa, nomes reservados do Windows, correção por renomear/editar com prévia), estado `Aa`/`aA` por site com re-verificação no boot e jobs (`case_parity`) e paridade Git (`parity::git_parity_init`). Proxies (`proxy`: upstream, WebSocket, headers, TLS → `ProxyModel`) e apps (`apps`: Procfile 2.0 com `$PORT`, `runtime: tool@série`, PATH determinístico, `autostart: on-visit`, um `InstanceActor` por process e um Job por site, via `forge-supervisor`; [ADR-0028](../../docs/adr/0028-app-processes-launch-path-on-visit.md), [docs/06 §4.4](../../docs/06-sites-vhosts-multi-php.md)).

**O que não é:** Não renderiza arquivos de configuração (isso é `forge-render`) e não mexe em DNS nem em certificados.

**Quem depende dele:** `forge-daemon`.

**Referência:** [docs/06-sites-vhosts-multi-php.md](../../docs/06-sites-vhosts-multi-php.md) (§1.3 descreve a implementação).

**Testes:** `tests/apps_windows.rs` (Node 20 real da máquina como `bin/nodejs/20.12.2`: HTTP + WebSocket, `npm run` via `cmd.exe`, `.nvmrc`, `on-visit`, Job por site; pula sem o Node 20 em Program Files), `tests/apps_spec.rs` (fixture `tests/fixtures/apps/nextjs/forgebox.yaml` → `AppSpec` e vhost nginx/apache/caddy) e `tests/nginx_proxy_online.rs` (`--ignored`: nginx 1.30.6 real do cache compartilhado proxia HTTP e WebSocket e serve a página de `on-visit`); fixtures em `tests/fixtures/projects/<nome>/` (só arquivos marcadores) e `tests/fixtures/case/` (aceite do Finder: 3 referências com caixa errada; os testes copiam para uma pasta temporária antes de corrigir) e snapshots `insta` em `tests/snapshots/` (`INSTA_UPDATE=always cargo test -p forge-sites` para atualizar).
